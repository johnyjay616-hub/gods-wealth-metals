# Gods Wealth Metals

Professional e-commerce starter website for Gods Wealth Metals.

## Included
- Responsive storefront
- Product categories
- Product cards
- Shopping cart
- NGN pricing
- About and contact sections
- Mobile-friendly design

## Next integrations
Payment gateway, WhatsApp ordering, delivery calculation, product database, customer accounts, and an admin dashboard can be connected as the store develops.

Open `index.html` to preview the storefront.
